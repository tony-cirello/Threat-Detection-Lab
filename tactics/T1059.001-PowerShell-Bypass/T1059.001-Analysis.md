# 🛡️ Threat Analysis: PowerShell Execution Policy Bypass (T1059.001)

## 📌 Executive Summary
**PowerShell Execution Policies** are a safety feature designed to prevent users from unintentionally executing untrusted script files (`.ps1`). However, Microsoft explicitly states that execution policies are **not a security boundary**. 

Adversaries frequently leverage command-line flags such as `-ExecutionPolicy Bypass`, `-ep bypass`, or `-EncodedCommand` to execute malicious scripts on compromised Windows endpoints while circumventing local execution restrictions.

---

## 🎯 Technical Threat Details
* **MITRE ATT&CK Tactic:** [TA0002 - Execution](https://attack.mitre.org/tactics/TA0002/)
* **MITRE ATT&CK Technique:** [T1059.001 - Command and Scripting Interpreter: PowerShell](https://attack.mitre.org/techniques/T1059/001/)
* **Target Platforms:** Windows 10, Windows 11, Windows Server (2016+)
* **Severity Level:** Medium / High (depending on parent process and user context)

### Attack Mechanics
When an attacker gains shell access or executes a malicious stager, they attempt to run un-signed PowerShell code. By passing execution bypass arguments, the `powershell.exe` engine initializes without enforcing execution policy checks set in the registry or Group Policy Object (GPO).
